# kbx v0.1.4

## kbx no longer writes to your notes by default

`kbx accept` and `a` in `kbx review` now keep accepted relations in `.kbx/`, for
every vault, including ones made by an earlier kbx. An accepted relation is still
a graph edge: it survives `kbx index --full`, and generators, `kbx lint` and
`kbx export` all see it.

To write to frontmatter as before, add this to `.kbx/kbx.toml`:

```toml
[write]
frontmatter = true
```

`kbx apply` then writes the relations `.kbx/` already holds, and
`kbx apply --dry-run` prints the diff first. `kbx suggest --stage`,
`kbx sync-stage` and the `kbx.reviewed` lock need the setting too.

`kbx init` now puts the config at `.kbx/kbx.toml` and creates nothing else at the
vault root. A `kbx.toml` at the root still works: `kbx doctor` warns about it, and
`kbx doctor --fix` moves it.

## Before you upgrade

- **New vaults use the built-in search engine.** It needs no Node and no qmd.
- **It downloads a 134 MB model on first use,** into your user cache:
  `~/Library/Caches/kbx/models/` on macOS, `~/.cache/kbx/models/` on Linux and
  `%LOCALAPPDATA%\kbx\models\` on Windows.
- **That model reads English only.** For notes in other languages, use
  `kbx init --search qmd`.
- **Existing vaults stay on QMD.** Their `kbx.toml` says `search = "qmd"`. To move
  one, change the key.
- **`kbx suggest` defaults to `--judge auto`, which can spend money or plan
  quota.** It sends excerpts of your notes to the logged-in `claude` or `codex`
  CLI, or failing those to local `ollama` or `llama-server`. Use `--judge none` to
  stop at the candidates, or `--budget-usd` to cap a run.
- **`kbx index` can now exit 1.** It does when files were found and the index holds
  no notes, so check any script that runs it.

## Pull requests

- #37: Accepted relations are stored in `.kbx/` by default, frontmatter writing
  moves behind `[write]`, the config moves to `.kbx/kbx.toml`, and `kbx apply` is
  new.
- #36: `kbx suggest` skips the search when the graph has no note to search, and
  says why.
- #35: The config can live in `.kbx/`, and `kbx accept --no-write` records a
  decision and prints the diff without touching a note.
- #34: `kbx index` reports what it left out, grouped by cause, and exits 1 when the
  index ends up with no notes.
- #33: Existing vaults index as they are: a missing `id`, `type` or `title` is
  inferred into the index and never written.
- #32: One exclusion rule keeps hidden folders, an `exclude` list and `.gitignore`d
  folders out of scopes, the index, search and the judge.
- #31: Unknown frontmatter keys are ignored, so a nested map outside `kbx:` and
  `qmd:` no longer fails the note.
- #30: The release workflow now starts the smoke checks itself.
- #29: `docs/e2e-hq.md` records the end-to-end run of v0.1.3 on a real vault, which
  stopped at `kbx index`.
- #28: The built-in search engine is the default for new vaults, and QMD stays an
  option with `kbx init --search qmd`.
- #27: Adds the built-in search engine, BM25 and a local embedding model, behind
  `search = "builtin"`.
